# Atlas Legal AI

Premium AI-powered legal intelligence and document automation platform for UK freelancers and small businesses.

## Key Features

- **Document Library**: 200+ UK-compliant legal templates (NDAs, Employment Contracts, Service Agreements, etc.)
- **AI Document Generator**: Interactive wizard UI with live assembly preview.
- **AI Contract Review**: Instant risk analysis and flagging for uploaded legal documents.
- **Legal Health Check**: Interactive quiz to identify business legal vulnerabilities.
- **Solicitor Network**: Directory of vetted UK solicitors for complex legal needs.
- **Legal Guides**: SEO/AEO optimized long-form editorial content.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Fonts**: Playfair Display (Serif) & Inter (Sans)

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design Philosophy

"Trusted, intelligent, accessible." Atlas Legal AI combines high-end legal authority with modern tech aesthetics. The design uses a palette of Deep Navy (#0D1B2A), Professional White, Accent Blue (#1565C0), and Gold Authority (#B8960C).
